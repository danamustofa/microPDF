## 🚀 Quick Reference

### Electron App
```bash
# Install dependencies
npm install

# Run app
npm start

# Build for production
npm run build:win
```

### CLI Script
```bash
# Install dependencies
pip install -r requirements.txt

# Interactive mode
python compress.py

# Quick mode
python compress.py -q

# Single file
python compress.py -s input.pdf

# Batch folder
python compress.py -b folder_pdfs
```
